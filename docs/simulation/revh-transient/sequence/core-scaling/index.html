Eight workers produce about 31% more timesteps per minute in this short check.

The Ryzen 7 5800X3D has eight physical cores and sixteen logical threads. This WSL instance exposes twelve logical threads. An independent four-worker startup simulation continued throughout these tests; the flowing production workers were suspended during each timed solve.

All candidates used the same 3.19-million-cell mesh, fan forcing, fields from steady iteration 300, two outer correction passes, output cadence, and four timesteps of 12.5 µs. The timing averages the last three steps, excluding initialization and the first step. The eight-worker trial uses logical CPU slots with affinity disabled, as in the other trials.

Both larger worker counts passed the predeclared field comparison against four workers: RMS error below 0.1% and maximum error below 1% of the corresponding reference magnitude, each with a 10−6 absolute allowance. The maximum velocity-component difference for eight workers was 0.000167 m/s; maximum pressure difference was 0.00572 Pa at the assumed density. All trials had maximum Courant number 0.367 and no turbulence bounding messages.

This is a short throughput and solver-equivalence check. It does not establish mesh independence, timestep independence, periodic vortex shedding, or long-run performance. Increasing the worker count does not improve the mesh itself.
