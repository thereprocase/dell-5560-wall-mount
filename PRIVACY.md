# Public snapshot privacy review

The October 2026 publication removes personal workstation usernames and hostnames
from documentation, source-path examples, solver logs, compressed logs and packaged
print assets. Commit authors use the public GitHub noreply identity.

Geometry, mesh topology, print toolpaths and scientific result data are preserved.
SHA-256 references for modified source, logs and packages are refreshed. Historical
engineering qualifications remain unchanged; this review is not physical validation.

The review includes nested ZIP/3MF/FreeCAD assets, gzip evidence, reconstructed
multipart CFD evidence, image metadata, PDF text and metadata, and release assets.
Upstream support contacts and license attributions remain intact.
