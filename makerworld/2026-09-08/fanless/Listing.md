# Minimal Laptop Wall Mount

Two open brackets hold a closed laptop against a wall. There are no fans, ducts, or backplate. Curved ribs and six tapered gussets per bracket put material around the contact tabs and wall connections.

This is the latest fanless design from the cloud-topo branch. It targets low material use while retaining an open grip area above the brackets.

**Early-adopter prototype:** physical fit and load testing remain open. Start with the fit coupon and a supported trial assembly.

## Fit and geometry

| Feature | Dimension |
|---|---|
| Reference laptop | 344.4 × 230.3 × 20 mm, closed |
| Slot width, normal to laptop faces | 22 mm |
| Nominal face clearance | 1 mm per face |
| Nominal side clearance | 0.5 mm per side |
| Outward lean | About 4.2° |
| Rear gap at bottom / top | 21.0 / 37.9 mm |
| Minimum gap in the upper grip region | 32 mm |
| Side web / contact reach / wall-pad reach | 4.8 / 16 / 24 mm |
| Fastener clearance | Four Ø7 mm holes |
| Washer / tool clearance | Ø15 / Ø16 mm envelopes |
| Vertical hole spacing | 114 mm |

The laptop slides down along the tilted slot. Lift it along that direction to remove it. Leave overhead space for this movement. Padding consumes the 1 mm face clearance; it has no separate allowance.

The mounting openings use peaked roofs around the round tool clearance. These roofs avoid broad, flat overhangs. Install the brackets with the laptop removed so the driver can approach each screw from the room.

## Print and fit

Print the fit coupon first. Check the laptop edge, bolt, washer, head, and driver with the actual hardware. Then print one left and one right bracket, broad outer cheek down. Preserve that orientation.

The new Bambu Studio projects use 0.20 mm layers, four walls, six top and bottom layers, and 20% gyroid infill. The P1S PETG HF slice estimates about 69.5 g for the pair, including the brim. This is a slicer estimate, not a measured print weight.

PLA Basic, PETG HF, and ASA have separate profiles. Material changes need their own fit and load checks. Extra walls cannot make PLA insensitive to heat or long-term loading.

## Development status

This is an unprinted fit and print prototype. CAD assembly, geometry checks, and virtual slicing do not establish a safe load rating. Physical fit, warm creep, fastening, and handling tests remain open. Port access, cable routing, and lid opening also need checks on the actual laptop.

The gallery shows CAD renders. The laptop is a simplified dimensional envelope. Revision and physical test results will be added as development continues. Reports should include the laptop dimensions, filament, printer, and revision.
