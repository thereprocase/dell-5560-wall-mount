## Accepted printing choices

Use native Bambu Studio projects and Bambu PLA Basic, PETG HF, and ASA. The owner explicitly chose Bambu Studio for this package, overriding the repository's Orca default for this work. All projects use a 0.4 mm nozzle, textured PEI plate, 0.20 mm layers, four walls, six top/bottom layers, and **20% gyroid infill**. Do not restore the historical 100% infill comparison setup.

P1S, X1C, P2S, H2S, H2D, and H2C each have all three materials. A1 has PLA and PETG only. A1 mini is excluded. Each family has twenty projects. The six modular raw presets do not each have a full sliced printer matrix.

Keep one MakerWorld model listing per family. Group supported printers under a profile where the platform permits and the configuration is actually compatible. This grouping has not been configured or confirmed in MakerWorld. The archived files retain separate printer-specific cached G-code; do not relabel one printer's toolpaths for another printer.

The two duct objects use build-plate tree supports for long slot-roof edges identified in Bambu toolpaths. Settings include slim trees, a 30-degree threshold, 0.20 mm top contact gap, three top interface layers, and 0.35 mm XY gap. Other objects have support disabled. The user wanted supports placed with handling and visible surfaces in mind; physical removal quality and full-channel fit remain to be tested. Brims are 8 mm for ASA and 5 mm for PLA/PETG.

Shell counts are a prototype baseline, not proof of strength. PLA heat and sustained-load creep still matter. Do not claim a load, temperature, cooling, or universal laptop-fit rating.

## Known preparation traps

- Earlier scratch duct projects could export successfully while omitting parts from active plates. Only the final fourteen-part, nine-plate `RevH` projects in the release are approved snapshot artifacts. Do not recover old seeds or `_TreeDucts` variants from a working directory.
- H2D/H2C imported projects needed explicit selected-nozzle assignments (`extruder_nozzle_stats` and `nozzle_volume_type`). Those are present in the final files. A stock machine JSON alone did not initialize them correctly for the imported ducted project.
- The Windows Bambu CLI needed writable TEMP/TMP directories and a writable output working directory. Pass a filename, rather than an absolute path, to `--export-3mf`. Full flattened system profiles and correct printer compatibility were needed. Console diagnostics were visible through a terminal when redirected GUI-process logs were empty.
- Orca 2.5.0-dev's CLI invocation crashed in this session, although the owner launched its GUI successfully. This did not establish that the owner's Orca installation was unusable. Leave a working instance alone.
- The legacy duct coupon checks retained key and pin interfaces. It does not validate the revised full-length fan-tray fit. M1.1 needs at least 43 mm upward removal clearance; 25 mm fans need spacers for the 27 mm seat.

Large files are stored as GitHub release assets. Repository documents and gallery images provide the durable entry point. Preserve this dated snapshot and add a new dated package for later geometry or profile revisions.
